# Dingjun · dingjunn.com

面试用个人网站：项目、文章、人生思考。

## 本地预览

```bash
python3 -m http.server 4173
```

打开 http://127.0.0.1:4173/

## 结构

- `index.html` 首页
- `projects.html` 项目
- `writing.html` 文章列表
- `thoughts.html` 思考列表
- `about.html` 关于
- `posts/` 单篇文章

把占位文案换成你的真实内容即可。域名上线时，把本目录部署到静态托管，再把 `dingjunn.com` 解析过去。
