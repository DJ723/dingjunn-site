2026 AI 应用 / 汽车销售

NEV Insight

新能源汽车智能推荐与销售决策平台

面向门店顾问和线上导购的选车工作台。客户报一次预算和关注点，系统给出 Top 5 车型推荐、竞品对比和可追溯的回答依据，并把这次沟通沉淀成能跟进的线索。

  • 推荐和客服拆成两个 Agent：一个按客户画像排序车型，一个基于 RAG 与联网搜索回答「这个价位谁的智驾更强」，调用链在界面上直接可见
  • 检索用混合检索（向量 + 关键词）兜住「续航 700km 以上」这类带硬条件的问法
  • 线索库把画像、推荐结果、跟进动作串成一条，避免推荐完就断掉
  • FastAPI
  • Vue3
  • TypeScript
  • SQLite
  • RAG
  • 多 Agent

2026 AI 应用 / 健康

NutriFit AI

健康轻食营养顾问平台

给轻食品牌和体重管理场景做的营养客服。先算基础代谢与推荐热量区间，再靠饮食记录和拍照识别把「今天吃了多少」变成数字，问答里每条营养建议都带引用来源。

  • 食物图片识别估热量：不要求用户逐项称重输入，拍一张照片就能落进记录
  • Agent 走 Plan-and-Solve + ReAct + Reflection，先规划再检索，最后自检答案有没有超出证据范围
  • 记忆分两层：会话内短期记忆，加上长期身体指标记忆，回访时不用重填档案
  • Vue3
  • FastAPI
  • RAG
  • 视觉识别

2026 AI 应用 / 医疗

医路通 Agent Pro

多智能体医疗问诊平台

互联网医院场景：患者描述症状，系统给出风险分层、建议科室和就诊紧迫度，再进入线上问诊、报告解读与预约挂号，另配一套独立的管理后台。

  • 结论必须可追溯：每条建议都挂 RAG 证据和 Agent 推理链路，不做「黑盒给个结果」
  • 化验单、CT 报告走视觉模型解析成结构化指标，再给异常原因解读与复查建议
  • 分诊、问诊、用药咨询各自独立编排，避免一个 Agent 同时承担互相冲突的目标
  • FastAPI
  • Vue3
  • Chroma
  • RAG
  • 多 Agent

2026 开源 Skill / macOS

mac-checkup

给 Agent 用的 macOS 体检流程

磁盘、睡眠策略、电池健康、后台自启，四项一次查完。它真正要解决的不是「怎么查」，而是「查完之后怎么不搞坏别人的电脑」。

  • 四阶段硬流程：只读扫描 → 出报告 → 用户逐条确认 → 才动手，任何一步都不许跳
  • 五个脚本各管一件事：扫描、安全清理（只进废纸篓、拒绝受保护路径）、电源策略应用与回滚、睡眠日志统计、充电上限提醒
  • references 里写的是真踩过的坑：移进废纸篓不释放空间、macOS 没有「合盖=休眠」、80% 充电上限没有命令行开关
